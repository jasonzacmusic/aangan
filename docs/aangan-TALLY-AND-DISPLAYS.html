The recording light and the door displays

What we are building, why it matters, and how to install it

What this is for

So that nobody ever walks into a take.

Right now the only way to know a recording is happening is to already know. Someone opens the studio door mid-take, a lesson is ruined, and the take is lost. The same happens with deliveries at the front door and family walking through.

Two things fix it. A light that anyone can see, and a screen at each door that says what is going on inside. Flick one switch and both change together.

Two halves, and they are not equally ready

This is the part worth understanding before anything is bought.

The light works on its own. Today.

The switch and the light both connect to the same ESP32 board in the studio. The board watches the switch and drives the light itself — no app, no internet, no Raspberry Pi. Flick the switch and the light changes instantly, even if the Wi-Fi is down.

About ₹1,100 of parts and it is finished.

The screens need the app connected first.

A screen at a door is a tablet showing a web page. That page has to read the studio's state from somewhere, and right now the Aangan app runs on simulated data — it cannot see the boards yet. A screen showing invented information is worse than no screen.

So: build the light first. Buy tablets after the app is connected.

How the light connects

Two free pins on board 1, the studio node. Nothing else on that board changes.

PinWhat connectsWires
23The switch one wire to pin 23, the other to GND. No power, no polarity.
18LED strip data pin 18 → level shifter input → strip DIN
—Strip power strip 5V and GND go to its own 5V supply, not the ESP32
The strip must have its own power supply. An LED strip at full brightness draws far more current than the ESP32 can give — trying it will brown out the board and every sensor on it will start misbehaving. Join the supply's ground to the ESP32's ground, or the strip will not understand the signal.
Why a level shifter. The ESP32 speaks at 3.3 volts; the strip expects 5. Short runs sometimes work without one, then fail intermittently when the room warms up — which is the worst kind of fault to chase. It costs ₹80. Fit it.

Installing it — in this order

1
Build it on the table first
Board, switch, level shifter and a short piece of strip, all on the bench with the board on a charger. Nothing goes on a wall until the switch changes the colour.
2
Test the switch on its own
Before the strip is connected, flick the switch and check the studio page at http://192.168.0.250 changes. If the switch does not register, the strip will not help.
3
Add the strip and its supply
Plug the 5V supply in last, after every wire is in place. Flick the switch — the strip should change colour immediately.
4
Then, and only then, mount it
Above the studio door, on the outside, so it is seen before someone opens it. High enough not to be knocked. The switch goes wherever the person recording can reach it without leaving the instrument.
What finished looks like: flick the switch, a light above the studio door turns red, and anyone approaching knows not to come in. Flick it back and it returns to green. No phone, no app, no internet needed — it keeps working in a power cut on the board's charger.

The screens — what they will do, and what they need first

Each screen is a small tablet on the wall beside a door, showing one page all day. The app already has all of this built:

ScreenShows
Studio doorRecording / Class / Available, in colour, readable from across the corridor
Front doorSame, plus the delivery code — type an OTP and the courier reads it off the screen, so nobody opens the door mid-take
EitherA QR code guests can scan for what is happening inside and how to behave
Three things must be settled before buying a tablet.

1. Is there a plug socket within cable reach of each door? A tablet on a wall needs power. If there is no socket there, this is the one part of the whole project that needs an electrician — check it before spending anything.

2. The app must read the real boards first. Today it shows invented numbers.

3. Each tablet needs kiosk software so it stays on one page, never sleeps, and comes back by itself after a power cut. Without it, a tablet is not a wall panel.
