So what is Day 1 actually for? Getting the Raspberry Pi running Home Assistant, and getting your first real sensors reporting into it. That is a full, satisfying day's work, it needs nobody external, and it de-risks everything that follows. You will see real door-open and door-closed readings on a screen by the end of the day.

WHAT YOU ARE BUILDING

SENSORS small boxes on walls, one per area │ they talk over your Wi-Fi ▼ RASPBERRY PI running Home Assistant │ this is the brain. It decides everything. │ it has its own dashboard — that is what you use on Day 1 ▼ PHONES · iPAD · WALL SCREENS Home Assistant Companion app (free, App Store) Aangan web app — connected later

Each small box is an ESP32 — a ₹400 chip with Wi-Fi. Sensors plug into it, it plugs into a phone charger, and it reports to the Pi. You have six of them, one per area of the house.

BEFORE YOU START — lay these out

  • The Raspberry Pi 5 and its official white power supply
  • One microSD card
  • A Mac or laptop, on the same Wi-Fi as everything else
  • An ethernet cable, if you can reach the router — makes the first boot much easier
  • One ESP32 board and its micro-USB cable
  • Two or three MC-38 door sensors and a few jumper wires (for testing on the bench)
  • A breadboard
Do not mount anything on a wall today. Everything on Day 1 happens on a table. Mounting comes after each sensor type is proven to work — otherwise you are on a ladder debugging.

STEP 1 · GET THE PI RUNNING

10 min

Install Raspberry Pi Imager on the Mac

Download it from raspberrypi.com/software. It is a normal Mac app — drag it to Applications.

5 min

Choose Home Assistant, not Raspberry Pi OS

Open Imager. Click CHOOSE DEVICE → Raspberry Pi 5.

Click CHOOSE OS → scroll to Other specific-purpose OS → Home assistants and home automation → Home Assistant → pick the Raspberry Pi 5 version.

This is the step people get wrong. Do not pick plain "Raspberry Pi OS". Home Assistant is its own operating system and it configures itself.
10 min

Write it to the card

Click CHOOSE STORAGE, pick the SD card, click NEXT and let it write. If it asks about custom settings, choose NO — Home Assistant does not need them.

15 min waiting

First boot

Card into the Pi. Ethernet cable to the router if you can. Power in last.

Now wait. The first boot downloads and installs itself and takes ten to fifteen minutes. The screen may show nothing useful. This is normal. Do not unplug it.

5 min

Open it on the Mac

In a browser, type exactly:

http://homeassistant.local:8123

Create the admin account. Name the home Aangan, set the location to Bangalore.

✓ You know it worked when: you see a Home Assistant dashboard with the weather and a map. The Pi is now the brain of the house.

STEP 2 · YOUR FIRST SENSOR NODE

10 min

Install the ESPHome add-on

In Home Assistant: Settings → Add-ons → Add-on Store → search ESPHome Device Builder → Install → Start. Turn on Show in sidebar.

ESPHome is the tool that programs the little Wi-Fi chips.

15 min

Program the first ESP32

Open ESPHome from the sidebar. Click + NEW DEVICE, name it studio-doors, choose ESP32.

When it gives you a configuration to edit, delete what is there and paste in the contents of studio-doors.yaml — that file is in our project folder under pi/house/esphome/. Jason or I will hand it to you.

Plug the ESP32 into the Mac with the micro-USB cable, click INSTALL → Plug into this computer, and pick the port that appears.

If no port appears: the cable is a charge-only cable. Swap it for a proper data cable. This wastes more time than any other single problem.
10 min

Wire two door sensors on the bench

An MC-38 has two parts — a switch with two wires, and a plain magnet with none.

Take the switch part. One wire goes to the pin labelled GPIO25, the other goes to any pin labelled GND. That is the whole circuit — no resistors, no polarity, either wire either way round.

Do the same for a second sensor using GPIO26.

5 min

Adopt it into Home Assistant

Go back to Home Assistant → Settings → Devices & Services. A box should appear saying a new ESPHome device was discovered. Click Configure and accept.

✓ You know it worked when: you click into the device and see Studio door leaf A and Studio door leaf B listed.

STEP 3 · PROVE IT — the moment that matters

5 min

Move the magnet

Hold the magnet against the switch body, then pull it away. Watch the sensor in Home Assistant.

✓ Magnet touching = Closed. Magnet away = Open. If that changes on screen within a second, the entire chain works — sensor, chip, Wi-Fi, Pi, dashboard. Every other sensor in this house is a variation of this exact thing.
If it does not change: check the two wires are on GPIO25 and GND and are pushed in properly. Nine times out of ten it is a loose jumper wire.
If you get this far, Day 1 is a success. Stop here if you want to. Everything below is bonus.

HOW TO CHECK EVERYTHING — the daily habit

Until the Aangan app is connected, Home Assistant's own dashboard is the app. It is genuinely good and you lose nothing by using it for now.

On a computer

http://homeassistant.local:8123

Click Settings → Devices & Services → ESPHome to see every node and whether it is online. A node that has stopped reporting shows as Unavailable — that is the single most useful thing to look at.

On a phone or the iPad

Install Home Assistant from the App Store — the official one, it is free. Open it, and it should find your house on the Wi-Fi automatically. Log in with the account you made in Step 5.

On iPhones, allow Critical Alerts when it asks. That permission is the only thing that lets an emergency ring through Silent mode. If you tap no, emergency alerts will be silent — and there is no second prompt.
When the Aangan app is connected later, nothing you set up on Day 1 changes. The app is a nicer face on the same Home Assistant underneath. Nothing gets rebuilt.
