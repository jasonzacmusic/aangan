Addendum to the three lists

Aangan · one decision + what is missing · 31 July 2026

The three lists are good. Silverline, SP Road and Amazon are internally consistent and the house side is nearly complete — you could build the whole sensor network from them. This sheet covers one decision that must be made first, and a short list of gaps.

1 · One decision before ordering — affects the Silverline list only

The Raspberry Pi DAC Pro is output-only. It has no analogue input. If you buy it, the music Pi runs Pianoteq and can never run Chorale — not later, not with software. Only one audio HAT fits the I2S bus, so this is decided at purchase.

That contradicts the goal you set: "Chorale and Piano Tech should be the first apps that should run successfully on the Pi." Both options below are reasonable — but pick one now.

Option A — Swap to HiFiBerry DAC2 ADC Pro

Line in and line out, 24-bit/192k, studio line level. One Pi runs Pianoteq and Chorale. Still a HAT — nothing external, nothing USB.

Cost: remove DAC Pro + XLR board (−₹4,500), add DAC2 ADC Pro (₹7,500 + shipping, direct from hifiberry.com) and 2× Behringer DI400P (₹2,000) to restore balanced XLR into the console. Net ≈ +₹5,000.

Option B — Keep the DAC Pro + XLR board

Native balanced XLR out, no DI boxes, first-party board. The Pi becomes a dedicated Pianoteq stage piano. Chorale stays on the Mac — where it already works, is notarized, and measured 13% CPU.

Cost: no change. Order the Silverline list exactly as written. Honestly a very defensible choice — the Mac is the more reliable harmonizer host anyway.

5 · One wiring note for the builder

The kitchen node carries four MQ-6 sensors. Each has a heater drawing roughly 150 mA, so run all four heaters from the 5 V rail, never through the ESP32's 3.3 V regulator — it cannot supply 600 mA and will brown out.

Keep their analogue outputs on ADC1 pins (GPIO 32–39). ADC2 stops working the moment Wi-Fi is enabled on an ESP32, and this node is Wi-Fi.
