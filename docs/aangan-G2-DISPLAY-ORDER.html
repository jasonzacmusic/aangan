How it connects (already programmed)

Board 1 stays inside with the mic. Every 100 ms it sends the dBA number over Wi-Fi (ESP-NOW, plus HTTP at 192.168.0.250). The door chip at 192.168.0.248 paints the puck. Below 52 dBA = green OK. At or above = amber WAIT. Rec / DND still comes from Studio Command and wins over the mic.
